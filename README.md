# 중일분실물DB

분실물·습득물 게시판, 상세 페이지, 댓글 기능을 제공하는 학교 게시판입니다. Node.js 18 이상과 내장 모듈만 사용합니다.

## 실행

1. 이 폴더에서 `npm start` 또는 `node server.js`를 실행합니다.
2. 브라우저에서 `http://localhost:3000`을 엽니다.

다른 기기에서 함께 쓰려면 서버를 학교에서 접근할 수 있는 주소에 배포하고 그 주소를 공유합니다. 게시물 데이터는 `data/posts.json`, 사진은 `uploads/`에 저장됩니다. 배포 서버의 저장 공간을 백업해 주세요.

## 사용

- 분실 게시물은 분실 장소만 입력합니다. 습득 게시물은 습득 장소와 보관 장소를 입력합니다.
- 간단 설명은 목록 카드에, 상세 설명은 게시물 상세 페이지에 표시됩니다.
- 분실 게시물 상세 페이지에서 누구나 닉네임과 댓글을 남길 수 있습니다.
- 게시물 수정·삭제는 카드의 버튼을 누르고 게시물 등록 때 설정한 비밀번호를 입력합니다.
- 상단의 테마 버튼으로 다크 모드를 켜거나 끌 수 있고, 선택은 브라우저에 저장됩니다.
- 비밀번호는 서버에서 scrypt로 해시해 저장합니다. 사진은 JPG, PNG, WEBP, GIF 형식으로 최대 5MB까지 올릴 수 있습니다.

## 코드 구성

- `js/`: 브라우저 API, 게시판 렌더링, 폼, 인증 창, 상세 페이지 모듈
- `server/`: 게시물 저장·사진, 입력 검증, 비밀번호 처리 모듈
- `server.js`: HTTP 서버 및 API 경로
- `styles.css`, `components.css`, `detail.css`: 화면 스타일
